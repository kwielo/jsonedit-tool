# jsonedit-tool

A two-pane JSON editing tool built with [vanilla-jsoneditor](https://github.com/josdejong/svelte-jsoneditor) and [Vite](https://vite.dev/).

The left pane is a text/code editor, the right pane is a tree editor. Use the middle buttons to copy content between panes or clear both.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Static output is written to `dist/`. Preview it locally with `npm run preview`.
